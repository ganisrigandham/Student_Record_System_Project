# Student Record System

## Project Description
Student Record System is a simple Python project used to manage student details.

## Features
- Add student records
- Search student by roll number
- Display all student records
- Exit the program

## Student Details
The system stores:
- Roll Number
- Student Name
- Branch
- Marks

## Technologies Used
- Python
- VS Code

## How to Run
1. Open the project in VS Code.
2. Open the terminal.
3. Run the following command:

```bash
python Student.py
